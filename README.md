# Sales Data Analysis Dashboard

## Overview

This project was completed as part of my Data Science Internship at Codomax Digital Solutions.

The project focuses on analyzing sales data using Python and presenting meaningful business insights through data visualization.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Work

- Data Analysis
- Data Visualization
- Business Insights
- CSV Data Export

## Visualizations

- Bar Chart
- Line Chart
- Pie Chart
- Histogram

## Key Insights

- Laptop recorded the highest sales.
- Mouse recorded the lowest sales.
- Electronics was the highest-performing category.
- Sales data was analyzed using Pandas.
- Matplotlib was used to create visualizations.
